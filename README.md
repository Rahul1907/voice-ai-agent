# Voice AI Agent Platform

A real-time browser Voice AI Agent platform built with TypeScript, NestJS, Next.js, LiveKit Agents, PostgreSQL + pgvector, Redis + BullMQ, and free-tier/local AI providers.

> **Status:** Work in progress (Phase 1 — Monorepo scaffold & tooling).

## Workspace Commands

```powershell
pnpm install       # Install all workspace dependencies
pnpm build         # Build all packages and apps
pnpm lint          # Lint all workspaces
pnpm typecheck     # Type-check all workspaces
pnpm test          # Run unit tests
pnpm format:check  # Check formatting with Prettier
```

See [IMPLEMENTATION_PLAN.md](./IMPLEMENTATION_PLAN.md) for the full architecture and build plan, and [docs/decisions.md](./docs/decisions.md) for recorded versions and architectural decisions.
